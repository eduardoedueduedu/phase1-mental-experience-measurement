# README — Phase 1 Research Dossier (English)

This package contains the proposed operational summary for Phase 1 in Brazilian Portuguese and English. The summary is a **public draft; not submitted or preregistered**.

## Included documents

1. `README_PT-BR.md` — this package README in Brazilian Portuguese.
2. `README_English.md` — this corresponding README in English.
3. `Dossie_Fase1_Sintese_v2.2_PT-BR.md` — the operational summary in Markdown, in Brazilian Portuguese.
4. `Dossie_Fase1_Sintese_v2.2_PT-BR.pdf` — the PDF summary, with “Português do Brasil / PT-BR” in its visible title and file metadata.
5. `Phase1_Research_Dossier_Summary_v2.2_English.md` — the complete English translation in Markdown.
6. `Phase1_Research_Dossier_Summary_v2.2_English.pdf` — the PDF translation, with “English” in its visible title and file metadata.

The `../MANIFEST.sha256` file is package integrity metadata. It lists hashes for the six documents above and does not hash itself.

## Scope and status

Phase 1 is a proposed study of comprehension and feasibility. It does not test the F×Q–S association, validate F, Q, or S, or report ethics approval, recruitment, data collection, or human results as having occurred. This package contains no raw data, human data, EEG, analytic code, or simulation results. The F×Q v2 DGP has not been run.
