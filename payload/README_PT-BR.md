# README — Dossiê de Pesquisa da Fase 1 (PT-BR)

Este pacote reúne a síntese operacional proposta para a Fase 1 em português do Brasil e em inglês. A síntese está em **rascunho público; não submetido nem pré-registrado**.

## Documentos incluídos

1. `README_PT-BR.md` — este README em português do Brasil.
2. `README_English.md` — README equivalente em inglês.
3. `Dossie_Fase1_Sintese_v2.2_PT-BR.md` — síntese operacional em Markdown, PT-BR.
4. `Dossie_Fase1_Sintese_v2.2_PT-BR.pdf` — síntese em PDF, com “Português do Brasil / PT-BR” no título visível e nos metadados do arquivo.
5. `Phase1_Research_Dossier_Summary_v2.2_English.md` — tradução completa da síntese em Markdown, em inglês.
6. `Phase1_Research_Dossier_Summary_v2.2_English.pdf` — tradução em PDF, com “English” no título visível e nos metadados do arquivo.

O manifesto `../MANIFEST.sha256` é metadado de integridade do pacote; lista os hashes dos seis documentos acima e não contém um hash de si próprio.

## Escopo e estado

A Fase 1 é uma proposta de estudo de compreensão e viabilidade. Não testa a associação F×Q–S, não valida F, Q ou S e não relata aprovação ética, recrutamento, coleta ou resultados humanos como já ocorridos. Este pacote não inclui dados brutos, dados humanos, EEG, código analítico ou resultados de simulação. O DGP F×Q v2 não foi executado.

## Orçamento

A síntese apresenta orçamento proposto de US$ 5.000, incluindo US$ 3.924 para sustento flexível do pesquisador. O financiamento não foi recebido nem aprovado; a divulgação pública dos valores está autorizada pelo proponente.
